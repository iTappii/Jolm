# Ревью Ш-17. API мест (+ серверная часть Ш-19)

- Дата: 2026-11-21
- Исполнитель: сабагент (Sonnet); ревью: основной агент
- Итог: **принято**. DoD выполнен: тесты на bbox, поиск RU/EN(/KK), «открыто сейчас» через
  полночь. 30 новых тестов, всего 111 зелёных. Smoke-запуск на dev-базе прошёл.

## Что сделано

- `GET /v1/places?bbox=&category=&q=&limit=&format=json|geojson` — пины для карты; категория
  учитывает дочерние (`food` → все кухни); поиск по ILIKE (с экранированием) + триграммная
  похожесть слов (опечатки, «Достық» ≈ «Достык»); bbox проверяется (≤ 2° по каждой оси), лимит ≤ 1000.
- `GET /v1/places/{id}` — карточка: название/описание с откатом языка и полем `name_lang`, цены,
  часы по дням, `open_now` по времени Алматы, одобренные фото, меню, `crowd: null` (до Ф15).
- `GET /v1/categories`, `GET /v1/curated-routes`, `GET /v1/curated-routes/{id}` (только опубликованные,
  только активные места).

## Что проверено ревьюером

- `is_open_now`: интервалы через полночь (в т. ч. вс → пн), круглосуточно 00:00–23:59, обеденный
  перерыв, отсутствие часов → `null`, перевод из UTC — логика верна.
- SQL параметризован; ILIKE экранирован; скрытые/закрытые места не отдаются.
- План запроса поиска на dev-базе: последовательное сканирование 2.7 тыс. строк, 5 мс —
  для Алматы приемлемо (условие `OR` по трём колонкам мешает индексу).
