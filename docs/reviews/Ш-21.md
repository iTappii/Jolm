# Ревью Ш-21. Общественный транспорт (+ общий файл OSM из ревью Ш-20)

- Дата: 2026-11-21
- Исполнитель: сабагент (Sonnet); ревью: основной агент
- Итог: **принято**. DoD выполнен: для 10 эталонных пар по Алматы есть осмысленный вариант.
  Ревьюер прогнал `make ci` — 177 тестов зелёные.

## Что сделано

- **Общий файл OSM** (замечание №1 из ревью Ш-20): `make osm-pbf` → `data/osm/cache/kazakhstan.osm.pbf`;
  от него зависят `import-osm`, `import-transit`, `valhalla-up`. Ревьюер перевёл на него и
  `maps/build_tiles.sh` (жёсткая ссылка в `maps/build/` для Docker) и пересобрал тайлы — размер
  совпал байт в байт с прошлой сборкой (22 535 121), Valhalla переиспользовал свои тайлы.
- Миграция `0004_transit.sql` (остановки, маршруты, порядок остановок). На `places` не ссылается —
  правило 8 плана не затрагивается.
- Импорт: 120 маршрутов (метро — 2 направления, 106 автобусных, 12 троллейбусных), 956 остановок;
  остановка/платформа одной остановки склеиваются; маршруты с перепутанным порядком участников
  отношения (25 шт.) пересортировываются по геометрии; идемпотентно.
- Поиск (`server/app/routing/transit.py`): до 1 пересадки, время = пешком (Valhalla) + ½ интервала +
  поездка + [пересадка ≤ 300 м + ожидание] + пешком; варианты медленнее пешей прогулки отбрасываются;
  часы работы транспорта; помечено `approximate`. Сеть в памяти процесса (~1 тыс. остановок, поиск ~20 мс).
- 34 теста: синтетическая сеть с `FakeRouter`, импорт на маленьком `.osm`, 10 эталонных пар
  (интеграционные, запускаются при живом Valhalla и данных).

## Замечания

| # | Важность | Замечание | Что нужно |
|---|---|---|---|
| 1 | **высокая** | Из настоящего терминала аэропорта (43.352, 77.041) транспорта нет — в OSM нет остановки ближе 2 км; эталонная пара сдвинута на остановку OSM. Аэропорт — главная точка входа туриста | Добавить остановку у терминала и маршруты аэропорта вручную (`transit_manual.csv` / админка тарифов и транспорта в Ш-22), проверить пару «терминал → центр» |
| 2 | средняя | Многие линии в OSM — одно направление; обратное достраивается теми же остановками (без учёта остановок на другой стороне улицы) | Принято для v1 (время близко); улучшать через UGC (SSOT §10.1) |
| 3 | средняя | Интервалы, скорости, коэффициент извилистости — допущения; автобус до Медеу 71 мин против реальных ~45–60 | Калибровать по реальным поездкам/данным пользователей; пометка «примерно» в UI обязательна |
| 4 | низкая | Кэш сети в памяти не сбрасывается после `make import-transit` | Перезапуск процесса; при админке транспорта — сброс по сигналу/версии данных |
| 5 | низкая | Маршрут, обрезанный краем bbox, может дать ложную связь на выходе/входе | Обрезать по региону с запасом или не соединять сегменты через разрыв |
| 6 | инфо | Тариф ~100 ₸ в CSV не проверен | Сид `transport_tariffs` в Ш-22 |
