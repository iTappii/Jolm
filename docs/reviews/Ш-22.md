# Ревью Ш-22. Стоимость и сводка вариантов

- Дата — 2026-11-21.
- Статус — готово. Проверено с локальными PostGIS и Valhalla.

## Тарифы

Миграция `0005_tariffs.sql` добавляет `transport_tariffs`. Действует последняя версия с
`valid_from` не позже даты поездки, а при совпавших датах — запись с большим `version_id`.
История защищена от изменений и удаления. Сид с примерными ценами можно применять повторно.
Авторизованный администратор добавляет версии в `/admin/tariffs`; отправка формы защищена CSRF.

Пешком — 0 ₸. Для самоката используется старт плюс минуты, для автобуса и метро — фиксированная
сумма за каждую посадку, для такси — подача плюс километры и минуты, для своей машины — топливо
по километрам. Парковка в v1 стоит 0 ₸. Тариф автобуса покрывает также троллейбусы и трамваи.
Варианты с отсутствующей ценой платного участка исключаются. Округление до тенге выполняется
по правилу half-up. Тесты применения миграции и защиты истории требуют PostGIS.

## API маршрутов

Публичный `POST /v1/directions` принимает `from` и один пункт назначения, `to` или `to_place_id`.
Координаты передаются объектами `{lat, lon}` в пределах области импорта Алматы, широта 43.00–43.45
и долгота 76.70–77.20 включительно. `to_place_id` — UUID активного места. `depart_at` принимает
ISO 8601 с часовым поясом. При его отсутствии используется текущее время Алматы.
Тариф подбирается по дате поездки в `Asia/Almaty`. Запланированная версия тарифа применяется,
если она уже действует в день поездки.

```sh
curl -X POST http://localhost:8000/v1/directions \
  -H 'Content-Type: application/json' \
  -d '{"from":{"lat":43.238,"lon":76.940},"to":{"lat":43.241,"lon":76.945},"depart_at":"2026-11-21T12:00:00+05:00"}'
```

Пример ответа для доступной пешей прогулки с тестовым маршрутизатором.

```json
[
  {
    "mode": "walk",
    "duration_s": 491.9,
    "distance_m": 655.9,
    "cost_kzt_min": 0,
    "cost_kzt_max": 0,
    "geometry": "_f`nqA_m`wqCozDowH",
    "approximate": true,
    "recommended": true
  }
]
```

Массив содержит доступные варианты `walk`, `scooter`, `bus`, `metro`, `taxi`, `car`. Геометрия
передаётся в polyline6, сумма — в целых тенге. Необязательный массив `steps` содержит участки
`walk`, `ride` или `maneuver` с временем, расстоянием и своей геометрией. У участка транспорта
могут быть названия остановок, идентификатор и номер маршрута, тип транспорта, число остановок
и ожидаемое время посадки. У манёвра может быть текстовая инструкция.

Одиночный пеший маршрут возвращается при длине до 5 км. Для `taxi` и `car` поля `duration_s_min`
и `duration_s_max` задают диапазон. `duration_s` и нижняя граница цены рассчитаны на основе
маршрута Valhalla без пробок. Верхняя граница времени и цены использует ×1.6 в будни с 07:00 до
10:00 и с 17:00 до 20:00 по Алматы, ×1.25 в остальные часы. Начало интервала включено, конец
исключён. Коэффициент для автомобиля — приближение расхода топлива в пробках. Для рекомендации
приоритет у прогулки до 15 минут включительно. Остальные варианты сравниваются по сумме времени
в секундах и верхней цены в тенге, затем по времени, цене и исходному порядку.

Ответ `200 []` означает отсутствие доступных вариантов. При частичном сбое возвращаются оставшиеся
варианты. Если сбой оставил запрос без вариантов, возвращается `503`. Неактивное или отсутствующее
место даёт `404`, а некорректные параметры или координаты за областью обслуживания — `422`.
Ошибки возвращаются в формате `{ "error": { "code": "…", "message": "…" } }`.

## Аэропорт

Сид добавляет остановки T1 `(43.3460325, 77.011753)` и T2 `(43.34745, 77.01127)` к проверенным
OSM-отношениям №92 (`3014420`) и ночного №3 (`19593601`). T1 использует положение узла OSM,
T2 — приблизительную точку на общедоступном подъезде. Координаты `(43.352, 77.041)` из прежней
передачи работы относятся к контрольной точке аэродрома.

Локальное время работы №92 — 06:00–23:00, ночного №3 — 23:00–06:00. Другие линии №3 сохраняют
обычное расписание. Окна проверяются по времени отправления запроса. Ожидание оценивается по
интервалам из OSM и общим параметрам города. Регрессии проверяют переходы между окнами и привязку
по OSM-отношению.
На реальной выгрузке проверены дневные варианты от обоих терминалов до площади Республики
с `FakeRouter`. Остановки ночного №3 в OSM описаны частично. Сквозной ночной маршрут до центра
пока не подтверждён.

Источники — [расписание аэропорта](https://alaport.com/en/transports/bus),
[схема проезда](https://informburo.kz/storage/photos/221/AT2NNNowgXmdxVZtX7PX6GYBOFXAJNAgylWHQDLm.jpg),
[координаты аэродромной точки в AIP](https://www.ans.kz/AIP/eAIP/2026-10-29-AIRAC/html/eAIP/UA-AD-2.UAAA-en-GB.html).
