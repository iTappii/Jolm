# Ревью Ш-14 — iOS-каркас

## Что сделано

- `Core/Networking`: `APIClient` (async/await, `final class` + внутренний actor для refresh).
  Ошибки `{"error":{"code","message"}}` декодируются в `APIError.server(status, code, message)`;
  транспортные — `.network(URLError)`; отмена не оборачивается. Заголовки: `Accept-Language`
  (из переопределения языка приложения, иначе язык системы), `X-Install-ID`, `Authorization: Bearer`
  из Keychain (`SessionStore`, через протокол `TokenStore`). На 401 — `POST /v1/auth/refresh` с
  single-flight (параллельные 401 дают один refresh) и один повтор запроса. Если сервер отклонил
  refresh (4xx, кроме 408/429), сессия очищается и вызывается `onSessionCleared` (обновляет
  `AuthState`). При сетевой ошибке или 5xx токены сохраняются.
- `SSEClient`: `SSEParser` (строки `event:`/`data:`/`id:`, комментарии, CRLF/CR/LF, многострочный
  `data`) и `APIClient.stream(_:)` → `AsyncThrowingStream<SSEEvent, Error>` поверх
  `URLSession.bytes`, с тем же 401 → refresh → повтор до начала потока.
- `InstallID`: UUID, один раз, в **UserDefaults**, а не в Keychain: это не секрет, и он должен
  сбрасываться при переустановке (нет сквозного отслеживания). Уходит в заголовке `X-Install-ID`.
- DI: `AppContainer` (`@MainActor @Observable`) в `App/`, подмешивается через `.environment`.
  `RootView` применяет `.environment(\.locale, …)` и бренд-tint. Корневой экран по-прежнему карта.
- Apple-вход переведён на `APIClient` через `AuthService` (`appleChallenge`, `signInWithApple`,
  `signOut`); поведение экрана прежнее. Проверка базового URL (https или localhost в симуляторе)
  вынесена в `AppConfig.resolveAPIBaseURL`.
- Локализация: `Localizable.xcstrings` (RU/EN), `LanguageSettings` (system/ru/en, UserDefaults).
  Смена языка применяется без перезапуска: `.environment(\.locale)` на корне переключает
  `Text("ключ")`, включая таблицы `AppleSignIn`. Для строк вне View — `L10n.string(_:language:)`.
  `InfoPlist.xcstrings` с текстом запроса геопозиции RU/EN уже был, проверен тестом.
- Дизайн-токены `Core/Design/`: цвета (`#FF7A00`, чёрный, нейтральные, динамические light/dark),
  типографика (на text styles, Dynamic Type), отступы, радиусы.
- Заглушки экранов: Chat, Places, Route, Trip, Profile (пока только выбор языка), Sidebar.
  Отладочная «галерея» (`-JolFeatureGallery`, только DEBUG): список экранов, переключатель языка,
  статус `/v1/meta` через `ServerStatusModel` (образец `@Observable`-модели фичи).
- `SWIFT_VERSION` = 6.0 (язык Swift 6, строгая конкурентность); сборка без предупреждений.
  UI-тесты помечены `@MainActor`. README обновлён.

## Замечания и отложенное

1. **средняя** — `AppleSignInUITests` не запускался (нужен реальный Apple ID); вход через
   Apple после переноса на `APIClient` проверен только сборкой и юнит-тестами клиента, не вручную.
2. **средняя** — сервер пока не знает заголовок `X-Install-ID`; он нужен в Ш-30/Ш-40, имя заголовка
   надо согласовать с сервером.
3. **низкая** — `AuthService.signOut` и `AuthState` не покрыты юнит-тестами; выход из аккаунта
   появится в UI в Ш-16.
4. **низкая** — смена языка проверена на `Text` и навигационных заголовках. Строки, созданные
   вне View через `String(localized:)`, язык переопределения не учитывают — для них использовать
   `L10n.string`. Системные элементы (клавиатура, `SignInWithAppleButton`) остаются на языке системы.
5. **низкая** — при ошибке Keychain после успешного refresh ротированный refresh-токен теряется
   (сессия фактически сброшена); сейчас ошибка пробрасывается вызывающему.
6. **низкая** — `SWIFT_VERSION = 6.0` включает строгую конкурентность; обновление MapLibre может
   потребовать `nonisolated(unsafe)` или обёрток.
7. **низкая** — офлайн/повторы запросов с backoff не реализованы (повтор только после refresh);
   добавить при необходимости в Ш-30+.
