- `maps/build_tiles.sh`: по умолчанию собирает страну (`AREA=kazakhstan`, bbox `46.4,40.5,87.4,55.5`) в

## Сервер: «Как добраться» по стране
- `POST /v1/directions`: точки проверяются через `region_for_point` — подходит ЛЮБОЙ регион таблицы
  (Алматы или `kazakhstan`); вне всех регионов — 422. Часовой пояс — региона отправления.
- Общественный транспорт строится только если обе точки в регионе по умолчанию (сеть остановок — Алматы);
  иначе его просто нет, ничего не выдумывается.
- Пешком отсекается правилом `MAX_WALK_M` = 5 км (уже было). Самокат раньше не имел предела — добавлен
  `MAX_SCOOTER_M` = 30 км (SSOT §6.1 п. 4). На 200+ км остаются «машина» и «такси».
- `GET /v1/geocode/reverse` — тоже по любому региону.
- Планировщик/генератор/живой маршрут остаются на регионе по умолчанию (не менялись).
