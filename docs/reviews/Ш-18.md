# Ревью Ш-18 — места на карте и карточки мест

## Что сделано

- **Слой мест** (`Features/Map/MapView.swift`, `MapCoordinator`): GeoJSON-источник `jol-pins` с кластеризацией MapLibre (радиус 44, до z15), кластеры — оранжевые круги со счётчиком, одиночные места — круглые иконки категории, выбранное место — кольцо. Тап: по кластеру приближает камеру, по месту открывает карточку, по пустому месту закрывает карточку. Хит-тест — по квадрату 44 pt вокруг тапа, берётся ближайшая фича.
- **Иконки категорий**: в стилях `maps/style` спрайта нет, поэтому иконки рисуются на лету из SF Symbols (цветной круг по группе категорий + белый символ) и регистрируются через `MLNStyle.setImage` при каждой загрузке стиля (`PlaceCategoryStyle`). Слаги — из миграции 0002; неизвестный слаг → общий пин, `cafe_*` → вилка/нож.
- **Загрузка по области** (`PlacesModel`): debounce 350 мс, новый запрос отменяет прошлый (отложенный и летящий), область запроса = экран + 25% (не более 2° — лимит сервера), `limit=1000`; если новый экран целиком внутри уже загруженной области и прошлый ответ не упёрся в лимит — запроса нет. Дедупликация по `id`, потолок 3000 мест в памяти (при превышении вне экрана остаются самые популярные), при ошибке — один автоповтор через 3 с, существующие пины сохраняются.
- **Карточки** (`PlaceCardSheet`, `PlaceCardView`): один sheet с двумя detent. Малый (270 pt, карта за ним остаётся интерактивной) — мини-карточка: фото-заглушка, название, категория, «Открыто сейчас/Закрыто», часы на сегодня, приблизительные цены (≈ N ₸), кнопки. Свайп вверх (`.large`) — полная карточка: большое фото, описание, адрес, цены, обычная длительность визита, часы по дням (сегодня выделен), сайт. Свайп вниз закрывает.
- **Кнопки**: «Бронирование — скоро» (отключена до Ф16), «Как добраться» (заглушка для Ш-23: `PlacesModel.requestDirections(to:)` запоминает запрос), «Открыть в навигаторе» — Apple Карты (`https://maps.apple.com/?daddr=…`) всегда, 2ГИС (`dgis://…/routeSearch/…/to/lon,lat`) только если приложение установлено (`canOpenURL` + `LSApplicationQueriesSchemes: dgis` в Info.plist); если вариантов два — меню. Только ссылки, данные чужих карт не копируются (SSOT §13).
- **Фото**: сервер отдаёт только `storage_key`, URL нет (`MEDIA_BASE_URL` — Ш-44), поэтому всегда заглушка с иконкой категории; модель уже читает необязательное поле `url` и покажет `AsyncImage`, когда оно появится.
- При выборе места чат сворачивается, карта сдвигается так, чтобы место было выше карточки (`contentInset`).
- **Тёмная тема карты** (из ревью Ш-15): `AppConfig.mapStyleURL(dark:)` заменяет `jol-light.json` на `jol-dark.json` на том же хосте; переключение системной темы меняет стиль на лету, слои и иконки ставятся заново.
- Для UI-тестов: DEBUG-аргумент `-JolStubAPI` — `URLProtocol` с фикстурами (`Core/Networking/UITestSupport.swift`) и офлайн-стиль `stub-style.json`. Фикстурное место лежит ровно в центре карты (центр экрана) — тап детерминирован.
- Строки в `Localizable.xcstrings` (RU/EN).

## Находки и замечания

| # | Важность | Замечание |
|---|---|---|
| 1 | **высокая** | В стилях `jol-light/dark.json` уже есть источник `jol-places` и слои `jol-places-circle/-label`, но кластеризацию у существующего источника не включить. Приложение удаляет эти слои и ставит свой источник `jol-pins`; линию маршрута `jol-route` переиспользует. Если стиль решат менять — учесть, что приложение зависит от id `jol-route`. |
| 2 | **высокая** | Шрифт подписей кластеров — «Noto Sans Bold» (как в стиле). Другой шрифт (например, «Open Sans Semibold») ломал отрисовку всего источника на реальном стиле (кластеры и пины пропадали) — нашли это отладкой; в офлайн-стабе без glyphs проблемы не видно. |
| 3 | **средняя** | `maps/serve.py` отдаёт только `/native/jol-light.json`; `/native/jol-dark.json` → 404, поэтому тёмный стиль на локальном сервере по умолчанию не откроется. Нужна одна строка в `serve.py` (раздавать и dark). Я проверял тёмный стиль временным скриптом на :8081 (в `scratchpad`), `maps/` не трогал. |
| 4 | средняя | Фото: нужен URL (`MEDIA_BASE_URL`, Ш-44). |
| 5 | низкая | Dev-база разрежена: у «Бахар Базары» и «Медеу» нет часов/цен/адреса — карточки с часами и ценами проверены только на фикстурах UI-теста. |
| 6 | низкая | «Как добраться» — заглушка; кнопка видна и нажимается, но ничего не показывает до Ш-23. |
| 7 | низкая | Глифы стиля идут с публичного demotiles.maplibre.org (уже TODO в `maps/README.md`). |
| 8 | низкая | Фильтр по категории (`category=` в API) и поиск пока без UI. |

Не проверено: Apple Карты/2ГИС открываются по ссылкам вручную не пробовали (в симуляторе Apple Карт нет, 2ГИС не установлен); Dynamic Type на малом detent.
