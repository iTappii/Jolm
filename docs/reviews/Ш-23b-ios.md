# Ревью Ш-23b (iOS часть) — избранные места

## Что сделано

- `FavoritesModel` (`Features/Favorites/`): `GET /v1/me/favorites` (элементы читаются как `PlaceSummary`, `address`/`created_at` пропускаются), `PUT|DELETE /v1/me/favorites/{place_id}`. Оптимистичное переключение с откатом при ошибке; 409 `favorites_limit` → «Список избранного заполнен», прочее → «Не удалось обновить избранное». 401 при загрузке очищает состояние. Список грузится при входе и очищается при выходе (`HomeScreen` `.task(id: isSignedIn)`).
- Кнопка «В избранное» (закреплена в листе места): вошедший — переключатель (заполненное сердце, «В избранном»); гость — гейт входа (Ш-28), после входа место добавляется.
- Боковая панель: «Избранное» → лист со списком (тап → карточка места на карте); гостю — гейт. Пустое состояние, ошибка с «Повторить».

## Проверки

- Юнит (`FavoritesTests`, 5): загрузка и ID, PUT/DELETE с `Authorization`, откат при 409 и при сбое удаления, 401.
- UI на заглушке (`FavoritesUITests`, 2): вошедший включает сердце, видит место в списке из боковой панели, открывает карточку, снимает; гость → гейт → вход → место добавлено.
- На реальном сервере кнопка вручную не проверялась (проверены directions и вход).

## Не сделано / замечания

- Не проверено на реальном сервере, переименование/сортировка списка не нужны по SSOT §11.5. Язык названий определяется заголовком `Accept-Language` (имя в списке не обновляется при смене языка без перезагрузки списка).
