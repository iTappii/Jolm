# Ревью доработки Ш-08: отношения OSM и связь ручных мест

- Дата: 2026-11-21
- Исполнитель: сабагент (Sonnet); ревью: основной агент
- Основание: замечания №2 и №3 из `docs/reviews/Ш-07-09.md`
- Итог: **принято**. `make ci` зелёный (119 тестов) — проверено ревьюером.

## Что сделано

- Импорт OSM читает мультиполигоны-отношения (`osm_type='relation'`), точку считает чистым
  Python (`data/osm/geometry.py`: центроид по площади; если он вне полигона или в дырке —
  точка внутри). Области из замкнутых путей пропускаются — путь уже импортирован, двойного импорта нет.
- Все 6 ручных мест подборки привязаны к объектам OSM (БАО, площадь Республики, музей Кастеева,
  Көк базар, Dostyk Plaza, Almaty Arena). Ручных строк в базе больше нет.
- `import_popular.py`: ручная строка либо получает OSM id, либо сливается с уже существующей
  OSM-строкой (часы, фото, меню, места в маршрутах, мероприятия переносятся без конфликтов
  уникальности), затем удаляется.
- Dev-база: 2710 → 2762 места (+56 отношений; парков 44 → 50, озёр 19 → 23, гор 165 → 187).
  Повторный импорт и сид — без вставок и слияний.

## Что проверено ревьюером

- Логика слияния: переносы с `NOT EXISTS` не нарушают `place_menu.place_id unique` и
  дубли места в одном маршруте; удаляется только строка с `osm_id IS NULL`.
- Тесты: геометрия (вогнутый полигон, дырка, вырожденный ввод), привязка, слияние, «далеко /
  другое название — не трогать», в реальном CSV нет ручных строк.
