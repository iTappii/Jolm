# Ревью Ш-20. Движок маршрутизации (Valhalla)

- Дата: 2026-11-21
- Исполнитель: сабагент (Sonnet); ревью: основной агент
- Итог: **принято**. DoD выполнен: интеграционный тест A→B по Алматы проходит для трёх профилей
  на живом Valhalla.

## Что сделано

- `ghcr.io/valhalla/valhalla-scripted:3.9.3` (официальный, нативный arm64) в compose под профилем
  `valhalla` — `make up` по-прежнему поднимает только Postgres. Порт только на `127.0.0.1`.
- Тайлы по всему Казахстану собираются за ~30 с (~590 МБ в томе); резать до Алматы не стали —
  пригодится для межгорода. `make valhalla-up / -down / -logs / -rebuild`.
- `server/app/routing/`: интерфейс `RoutingProvider` (`route`, `matrix`), `ValhallaRouter`
  (таймауты, 2 повтора только на ошибке соединения, разбиение матрицы по 50 точек, недостижимые
  пары → `None`), `FakeRouter` для тестов и dev без Valhalla, `make_router(url)`. Режимы
  `walk / scooter / car` ↔ costing — в одном месте.
- 19 тестов: фейк, разбор записанных ответов Valhalla, повторы/ошибки через `MockTransport`,
  интеграционные (пропускаются, если Valhalla не запущен).

## Замечания

| # | Важность | Замечание | Что нужно |
|---|---|---|---|
| 1 | средняя | Valhalla монтирует PBF из `maps/build/` — артефакта сборки тайлов. Если файла нет, Docker создаст на его месте пустую папку и сборка упадёт непонятно | Вынести выгрузку OSM в один общий путь (скрипт `data/osm/fetch_pbf.sh` + цель `make osm-pbf`), от которого зависят `tiles`, `import-osm` и `valhalla-up` |
| 2 | средняя | Время на машине — без пробок: в Алматы в час пик реальное время в 1.5–2 раза больше | Для такси/машины в Ш-22 показывать диапазон «от–до» с коэффициентом пиковых часов; отметить как «примерно» |
| 3 | низкая | Самокат = велосипедный профиль, без учёта правил для самокатов | Принято для v1 (в плане это и предполагалось) |
| 4 | низкая | При ошибке «слишком далеко» в чанке матрицы — откат на попарные запросы (до 2500 запросов) | Для Алматы не случается; для межгорода поднять лимиты в `valhalla.json` |
| 5 | инфо | Координата нижней станции Кок-Тобе в тесте — приблизительная | Не влияет на проверку |
