# Ревью Ш-19 — готовые маршруты для гостя (iOS-часть)

## Что сделано

- **Вход**: боковая панель (свайп слева / кнопка) → строка «Готовые маршруты». Главный экран остаётся чистым.
- **Список** (`CuratedRoutesSheet`): `GET /v1/curated-routes`, название, описание, «N мест»; состояния загрузки, пусто, ошибка с повтором.
- **Просмотр маршрута**: `GET /v1/curated-routes/{id}` → на карте остановки по порядку (оранжевые кружки с номерами), линия между ними прямыми отрезками (реальная маршрутизация — Ш-23), камера вписывает все точки. Обычные пины на время маршрута скрыты, загрузка мест приостановлена; закрытие маршрута (X) возвращает пины.
- **`RouteBar`**: заголовок, кнопка закрытия и горизонтальный список остановок; тап по остановке (в списке или на карте) открывает карточку места из Ш-18.
- Линия рисуется слоями `jol-route-casing`/`jol-route` самого стиля (источник `jol-route`); если стиля с ними нет (заглушка, placeholder) — рисует свой слой.
