# Ревью Ш-48 (iOS) — мероприятия на карте

## Что сделано

- **Основная карта**: `EventsModel` (`Features/Events`) запрашивает `GET /v1/events?from=&to=&bbox=` на 14 дней вперёд (даты Алматы) для видимой области — с отложенным запросом и запасом по краям, как пины мест. Мероприятие — фиолетовая точка с подписью; у рекламного в подписи префикс метки («Ad · …»).
- **Полная карта маршрута**: мероприятия на даты поездки (`GET /v1/events?from=&to=` по датам поездки; при ошибке — поле `events` из `GET /v1/trips/{id}`).
- **Карточка** (`EventCardSheet`): название, даты и время (Алматы), цена, организатор, описание, кнопка «место» (открывает карточку места, если у события есть `place`). Тап по точке закрывает карточку места и открывает карточку мероприятия, и наоборот.
- **Метка «Реклама / Ad»**: показывается, когда сервер прислал `is_ad: true`, текстом `ad_label` (если пуст — «Ad»): оранжевый значок в карточке мероприятия, в списке «События здесь» на карточке места и в подписи точки. Клиент ничего не решает про достопримечательности и госместа — это делает сервер.
- Карточка места показывает блок «События здесь» (`events` до 5 штук).

## Проверки

- Юнит: разбор `is_ad`/`ad_label`, метка не выдумывается для обычных; параметры запроса (`from`, `to`, `bbox`), выбор события.
- UI: карточка события с меткой Ad открывается и содержит название, время и метку (для этого тест запускает приложение с `-JolStubSelectEvent`: офлайн-стиль заглушки не рисует круговые слои, поэтому тапнуть по точке на нём нельзя). Точка и тап по ней проверены вручную на реальных тайлах: `/private/tmp/claude-501/-Users-ramazannurahunov--claude-spares-spare-jlg9ow/cd2828c5-189b-4c50-a996-9b0538ff97d7/scratchpad/event-pin-ad.png` (точки, подпись «Ad · Fixture Jazz Night»), `/private/tmp/claude-501/-Users-ramazannurahunov--claude-spares-spare-jlg9ow/cd2828c5-189b-4c50-a996-9b0538ff97d7/scratchpad/event-card-ad.png` (карточка с меткой).

## Не сделано / ограничения

- Точки событий не кластеризуются; при большом числе подписи перекрываются.
- Нет фильтра по дням на основной карте (всегда 14 дней вперёд) и значка по категории события.
- Покупка билета на событие из карточки не оформляется (см. Ш-49).

## Пробелы серверного API

- Блок «Реализация» ревью Ш-48 не называл форму метки; по коду это `is_ad` + `ad_label` (ru/en) в каждом элементе `/v1/events`, `events` поездки и карточки места.
- У события нет фото и ссылки; кнопки «открыть сайт организатора» нет.
