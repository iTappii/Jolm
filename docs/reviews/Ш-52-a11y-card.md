# Ревью Ш-52 (доступность): карточка места, формы контента, избранное, вход

Область: `Features/Places/PlaceCard*`, вкладки «Обзор / Отзывы / Фото», карточка адреса/точки (Ш-23c), `Features/Content`,
`Features/Favorites`, `Features/Auth`. Карта, поездка, «Как добраться», события, бронь, чат, профиль, боковая панель
не трогались (другие ветки).

## Что найдено и исправлено

1. **Тёмная тема.** Жёстких светлых цветов в этих экранах нет (все цвета — токены `JolColor`, динамические). Найдены два
   места с недостаточным контрастом: системный зелёный «Open now» на белом (2,4:1) и фирменный оранжевый `#FF7A00` как
   текст/тонкая иконка на белом (2,7:1; звёзды, «В избранном», иконки). Добавлены `JolColor.statusOpen` и
   `JolColor.brandText` (`Core/Design/Accessibility.swift`: ≈5:1 в светлой, `#FF7A00` в тёмной), подсказки в форме входа
   переведены с `textTertiary` на `textSecondary`. Заливки оранжевым с чёрным текстом (8:1) не менялись.
2. **Dynamic Type до AX3.**
   - Закреплённая панель: на размерах доступности «В избранное» — только сердце (подпись для VoiceOver осталась), «Маршрут»
     на всю ширину; кнопки не обрезаются и не уходят за экран.
   - Лист карточки на AX3 открывается на половине экрана, а не на трети (треть вмещала только фото и пол-заголовка).
   - Вкладки на AX3 — одна строка, прокручиваемая вбок (в три строки друг под другом они съедали карточку);
     пустая плитка-заглушка фото на AX скрывается; название и адрес без `lineLimit`.
   - Строки «часы», «цены», «категория / открыто», отзыв (звёзды / дата / автор), форма меню, «Изменить / Повторить»
     в коде — `AdaptiveStack`: в строку, а на AX в столбец, ничего не сжимается.
   - Поле кода: шрифт был фиксированным 28 pt — теперь `.title` (масштабируется), высоты кнопок входа — `minHeight`,
     значок категории в избранном — `@ScaledMetric`, экран результата отправки прокручивается.
3. **VoiceOver.** Звёзды формы — кнопки «N из 5» с трейтом «выбрано», группа «Оценка»; звёзды в отзыве — «4 из 5»
   одним элементом; вкладки — группа «Разделы карточки», выбранная — `isSelected`; декоративные иконки (пустые состояния,
   сердце, значок точки, значок категории, результат отправки) скрыты; индикаторы загрузки — «Загрузка»; фото-превью —
   «Выбранное фото»; поле кода — один элемент «6-digit code» с подсказкой, куда ушёл код; заголовок «Enter the code» — header;
   неактивная кнопка Apple — «Пока недоступно»; сайт места — подсказка «Открывает сайт».
4. **Цели касания ≥ 44 pt.** Вкладки, «Маршрут», «Добавить данные», «Написать отзыв», звёзды, сайт, «Повторить»,
   «Изменить / Отправить код ещё раз», строка избранного, поля входа и кода — не меньше 44 pt (`minTapTarget`, `minHeight`).
   Тест проверяет размер и положение на экране у «Маршрут», сердца, звёзд, поля, кнопки отправки, «Изменить» и «Повторить».

## Замечания (по важности)

1. **Средне (чужая область).** Отступ карты под карточкой (`HomeScreen.mapBottomInset`) считает треть экрана; на AX3 лист
   открывается на половине, и выбранный пин может оказаться под листом. Нужно, чтобы владелец `Home` учёл `dynamicTypeSize`.
2. **Средне (чужая область).** В тесте на AX3 не нашёлся `trip-stop-2` в панели «Мои поездки» (путь к кафе через
   боковую панель и карту поездки) — возможно, нужен скролл; передать владельцу `TripMap`. Тест отзывов поэтому
   использует флаг заглушки `-JolStubReviewsForAll` и музей.
3. **Средне (не проверено).** VoiceOver на живом устройстве и Switch Control не запускались: проверены доступность
   элементов, метки, трейты и размеры через XCUI, а не голосовой вывод. Контраст посчитан по токенам, не измерен на экране.
4. **Низко.** На AX3 в форме отправки и входа много текста: экран длинный и прокручивается, клавиатура закрывает кнопку
   (в тесте её достигает «Продолжить» на клавиатуре); сворачивание клавиатуры — жестом прокрутки (`scrollDismissesKeyboard`).
5. **Низко.** «Reduce Motion», «Bold Text», «Increase Contrast», «Smart Invert» отдельно не проверялись.
6. **Низко.** Тёмная карта MapLibre — отдельная тема стиля (Ш-18), здесь не менялась.
