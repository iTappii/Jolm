- Итог: **принято**. DoD выполнен: найти место, поменять цену и часы работы, создать готовый

## Что сделано

- `/admin` на Jinja2 + htmx 1.9.12 (лежит в репозитории, не CDN), миграция `0003_admins.sql`
  (`admins`, `admin_sessions`, `admin_login_attempts`), CLI `make admin-create EMAIL=…`.
- Разделы: места (поиск RU/EN/KK, фильтры, пагинация, правка всех полей и часов работы,
  фото — заглушка до Ш-44), категории, готовые маршруты (создание, места, порядок, публикация),
  мероприятия (метка промо — `OPEN(SSOT §16.9)`).
- Каждое изменённое в админке поле попадает в `manual_override` (часы — как `hours`), поэтому
  импорт OSM его не перетрёт. Записываются только реально изменённые поля.

## Безопасность — проверено ревьюером

- Пароли: argon2id; для неизвестной почты проверка по фиктивному хешу (нет утечки по времени).
  Пароль в CLI — только через `getpass`/stdin, не в аргументах и не в логах.
- Сессия: 256-битный токен в cookie `HttpOnly`, `SameSite=Lax`, путь `/admin`, `Secure` вне dev;
  в базе только sha256 токена; 12 ч; выход отзывает сессию.
- CSRF на всех POST (HMAC от токена сессии; на форме входа — double-submit cookie).
- Ограничение попыток входа в базе: 5 неудач на (почта, IP) за 15 мин, 20 на IP.
- Заголовки: строгий CSP без inline-скриптов, `X-Frame-Options: DENY`, `nosniff`, `no-store`.
- SQL: только параметры; `ILIKE` экранирует `%`/`_`; динамический SQL — только жёсткий белый
  список колонок. Тест на попытку SQL-инъекции в поиске есть.

## Исправления (2026-11-21)

Замечание №1 (IP за прокси) закрыто в Ш-51. Единственная функция `app/clientip.py::client_ip`
используется везде, где нужен адрес клиента, включая вход в админку; прежний `client_ip` в
`admin/api.py` (`request.client.host`) удалён. `X-Forwarded-For` учитывается только если TCP-адрес
входит в `TRUSTED_PROXIES`; читается справа налево, первый недоверенный адрес считается клиентом,
поддельные записи слева не используются. uvicorn запускается с `--no-proxy-headers` (образ и
`make run`), чтобы не подменял адрес до этой проверки. Тесты: `server/tests/test_clientip.py`
(в том числе подделка заголовка). Лимит неудачных входов в админку уже хранился в
`admin_login_attempts`, то есть был общим для процессов. Подробности: `Ш-51.md`.
