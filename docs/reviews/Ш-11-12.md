# Ревью Ш-11, Ш-12. Векторные тайлы и стиль карты Jol

- Дата: 2026-11-21
- Исполнитель: сабагент (Sonnet); ревью: основной агент
- Итог: **принято**. Ш-11 — DoD выполнен полностью. Ш-12 — выполнен с оговоркой: CLI
  `gl-style-validate` не запускался (нет node), стили провалидированы при загрузке в
  MapLibre GL JS 4.7.1 (`setStyle` валидирует по спецификации) — ошибок нет.

## Что сделано

- `maps/build_tiles.sh` — одна команда (`make tiles`): выгрузка Казахстана с Geofabrik →
  Planetiler (OpenMapTiles) по bbox `76.6,42.95,77.35,43.45` (Алматы + Медеу, Шымбулак, БАО,
  Кок-Жайляу) → `maps/build/almaty.pmtiles` (22 МБ, z0–14, сборка 23 с). Docker или jar (Java 21+).
- `maps/serve.py` — статический сервер с Range + CORS (`make tiles-serve`), `maps/demo/index.html`.
- `maps/style/build_styles.py` → `jol-light.json`, `jol-dark.json` (подписи RU) и `*.en.json` (EN).
  Акцент `#FF7A00`, пустые GeoJSON-источники `jol-route` / `jol-places` для маршрута и мест.
  Атрибуция «© OpenStreetMap contributors» в источнике.
- Агент проверил в браузере: Алматы рисуется с дорогами, парками, водой, подписи «Алматы» /
  «проспект Назарбаева» (RU) и «Almaty» (EN), Range-запросы отдают 206.

## Что проверено ревьюером

- Скрипты прочитаны; все 4 стиля генерируются заново (`make tiles-styles`) и парсятся;
  метаданные `jol:theme` / `jol:label-lang` на месте; `make -n tiles` корректен.
