# Ревью Ш-07, Ш-08, Ш-09. Данные мест

- Дата: 2026-11-21
- Исполнитель: сабагент (Sonnet); ревью: основной агент
- Итог: **принято** после исправлений ревьюера. DoD всех трёх шагов выполнен; `make ci`
  зелёный (ruff по `server db data`, 42 теста).

## Что сделано

- **Ш-07:** `0002_places.sql` — категории, места (GIST по `geom`, индекс `status`, trigram по
  `name_ru/name_en`, `unique(osm_type, osm_id)`), часы, фото, меню, готовые маршруты, мероприятия;
  CHECK-ограничения, деньги в `bigint *_kzt`, метки `OPEN(SSOT §16.1/2/9)`. Сид 40 категорий RU/EN
  с флагом `outdoor`. `BBOX_SEARCH` + тесты.
- **Ш-08:** импорт OSM (pyosmium) по bbox Алматы с горами: 2704 места за ~10 с, повторный запуск
  идемпотентен (0 вставок). Чистые функции маппинга тегов и парсинга `opening_hours` покрыты тестами;
  `manual_override` защищает ручные поля и часы.
- **Ш-09:** `popular_places.csv` — 102 места (96 связаны с OSM, 6 ручных), у всех `typical_visit_min`
  и `setting`; цены не выдуманы (пусто = проверить вручную). Импортёр помечает свои поля в
  `manual_override`, повторный запуск — 0 вставок.

## Что проверено ревьюером

- Миграция, SQL мест, upsert, CSV. Правило «без ORM» соблюдено; upsert собирает SQL из
  жёсткого белого списка колонок, значения — только параметрами.
- Координаты 6 ручных мест сверены с выгрузкой OSM (поиск по названию в `.pbf`).
