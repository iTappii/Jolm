- **«Маршрут»** (`Features/Directions/`): `DirectionsModel` → геопозиция (`LocationProviding`/`CoreLocationProvider`: запрос разрешения, один фикс, таймаут 10 с) → `POST /v1/directions` (без токена, работает для гостя). Нет доступа / нет фикса / вне Алматы → автоматически «от центра карты» с пояснением на экране и кнопками «Настройки», «От меня», «От центра карты». Центр карты вне Алматы → понятная ошибка без запроса.
- **Карусель по кругу** (`DirectionsPanel+Carousel.swift`): страницы пешком → общественный транспорт (автобус и метро вместе) → такси → самокат → своё авто → снова пешком; свайп влево/вправо (и VoiceOver-adjustable), плашки-иконки с лучшим временем для прыжка. Способов, которых сервер не вернул, нет. Открывается на странице с `recommended` (решение, см. ниже). На странице до 4 вариантов; у каждого: время (диапазон для такси/авто), **время прибытия** («Будете в 14:35», `arrive_at` сервера, иначе момент ответа + `duration_s`, Алматы), цена «от–до» или «≈», расстояние, «Рекомендуем»/«Оптимальный», номера маршрутов («62 → 1»), **слот загруженности** — рисуется только если пришёл `congestion.level` (сейчас `null` → ничего, данных не выдумываем).
- **Карта**: все варианты страницы линиями (выбранный — синий толстый, остальные бледные), точка старта, камера вписывает все линии при смене страницы, но не прыгает при выборе варианта. Декодер polyline6 — `Polyline.decode`.
- Лист в режиме маршрута открывается на 1/2 экрана (линии остаются видны), карта сдвигается по высоте листа.

## Контракт `POST /v1/directions` (Ш-22a), как его понимает клиент

Плоский список опций (`{"options":[...]}` или голый массив — принимаются оба; сервер сейчас отдаёт голый массив). У опции текущие поля (`mode, duration_s, duration_s_min/max, distance_m, cost_kzt_min/max, geometry, steps, approximate, recommended`) плюс необязательные: `group` (`walk|transit|taxi|scooter|car`, автобус и метро → `transit`), `variant` (0 — оптимальный в группе, дальше 1, 2), `arrive_at` (ISO-время со смещением), `congestion` (`null` или объект; клиент читает `{"level":"low|medium|high"}`, всё остальное игнорирует). Нет полей — группа по режиму, `variant` = 0, прибытие = момент ответа + `duration_s`. Внутри страницы сортировка по `(variant, duration_s)`.

## Решения и замечания

1. Карусель открывается на странице с рекомендацией сервера, а не на «пешком»: на городских расстояниях пешком 50 минут. Если нужен именно старт с первой страницы — одна строка в `DirectionsModel`.
2. Сервер сейчас отдаёт голый массив, а не `{"options": []}`; клиент принимает оба.
3. Тап по зданию/произвольной точке карты (не по пину) карточку не открывает: у сервера нет обратного геокодирования, карточки есть только у мест из базы. Не сделано.
4. Первый фикс геопозиции в симуляторе занимает ~8 с (экран «Определяем местоположение…»); таймаут 10 с, дальше — центр карты.
5. Сервер выдаёт у разных вариантов `bus` одинаковый `mode` — клиент не ключует по режиму, только по индексу.
6. Не проверено: настоящее устройство (GPS, диалог разрешения на «Не разрешать»), Apple Карты/2ГИС по ссылкам, Dynamic Type, тёмная тема листа.
