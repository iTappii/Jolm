# Ревью Ш-61 (сервер) — планировщик поездки по стране

Ветка `sh-61-server` (от `sh-22-24-auth`). SSOT §5.4 п. 1–4, 6, §7.2, §5.2. iOS-часть — отдельный агент (контракт JSON ниже),
чат и живой маршрут (`live_route.py`) — Ш-62, здесь не тронуты.

## Что сделано

- **`server/app/planner/country.py`** (новый): слой над городским планировщиком для пожеланий вне домашнего города.
  1. Далёкие пожелания (дальше `local_radius_km` от центра региона) группируются по направлению (single linkage,
     `group_radius_km`): Чарын и Кольсай — одна поездка, Туркестан — отдельная.
  2. Группа дальше `transfer_min_km` — **переезд** между городами (самолёт / поезд / автобус из `intercity.service`, самый
     быстрый «по карману»); ближе — **выезд** на машине из домашнего города.
  3. Выезд — однодневный (туда и обратно), если дорога в одну сторону ≤ `day_trip_max_oneway_h`, иначе **с ночёвками**
     (ближайший к следующему месту ночлег в `stay_search_km`). Слово человека (`stay_wishes`) сильнее дороги.
  4. **Умный порядок**: внутри группы — по времени дороги от дома (Кольсай на карте ближе Чарына, по дороге дальше),
     пожелание с датой — первым; переезды в другие города — в конец поездки, самый дальний город последним.
  5. **Пожелание с датой жёсткое**: блок встаёт на эту дату; если место из-за дороги «приземлилось» не в свой день,
     сдвигается весь блок (раньше), а не место; не получается — место в `unplaced` (`no_time`), не молча. Два пожелания с
     разными датами в одном направлении — два выезда.
  6. **Дорога — часть дня**: каждая остановка поставлена после реальной дороги (Valhalla через `intercity.service` от 50 км),
     день берёт только то, что влезает между началом и концом дня. Вечерний переезд к ночлегу и дорога домой после выезда —
     не остановки: время зарезервировано в дне, стоимость идёт в `DayPlan.extra_transport_kzt` (бюджет, транспорт).
     День, целиком занятый дорогой (долгая дорога туда или возврат), — `kind = "transfer"` без остановок.
  7. Медленный переезд (поезд/автобус) идёт **ночью**: отправление в `night_departure_min` (20:00) предыдущего дня, ночь в
     пути (в `overnight` — город назначения, койка не оплачивается). Первый день поездки так уехать не может.
  8. Дни, которые остались, — домашнего города: `plan_days` как раньше.
- **`planner/layout.py`**: `plan_days(..., pinned=)` (пожелание с датой не уходит с дня; без `pinned` код тот же),
  `DayPlan.kind/overnight/extra_transport_kzt`, `Leg.intercity`.
- **`planner/build.py`**: `build_plan` собирает домашний план и дальнюю часть, считает ночи и ночлеги по каждой точке
  (`StayPlan`), `overnight` каждого дня. Без дальних пожеланий и без пожеланий с датой — **ровно прежний путь**
  (`plan_days(dates, …)`, `trip_nights`), проверено тестом идентичности.
- **`planner/budget.py`**: `LodgingPlan.extra_kzt` (ночёвки в других точках; варианты «убрать места / дешевле» меняют
  только домашние), `Costs.extra_transport`.
- **`planner/candidates.py` + `sql.FAR_BY_POINT`**: пожелание, называющее известное место страны (Ш-56 `outside.py`), теперь
  ищется в базе возле его точки (25 км); нашлось — настоящее обязательное место, нет — `outside_area`, как раньше.
- **Бриф** (`chat/brief.py`, `chat/store.py`): `dated_wishes` `[{wish, date}]` (пожелание с датой также попадает в
  `must_haves`) и `stay_wishes` `[{wish, stay: day|overnight}]`; пустые списки по умолчанию, старые брифы без ключей читаются.
- **Хранение**: миграция `0033_country_planner.sql`: `country_planner_settings`, `trips.day_meta`, `trip_legs.intercity`,
  `trip_lodging_options.stay`, `trip_briefs.dated_wishes/stay_wishes`. `trips/store.py`, `read.py`, `edit.py` (пересчёт
  бюджета после правок не теряет «невидимую» дорогу), `api.py` (режимы `plane|train|tour` в `POST …/legs/{id}/mode`),
  `routing/schemas.py` (`Mode`, `Group = "intercity"`), `analytics/events.py` (`directions_start.mode`).
- **Данные**: `data/seed/country_planner.sql` (числа), `country_places.csv` (Чарынский каньон — OSM way 22722438;
  Кольсайские озёра — центр озёр, OSM node 5043328221; мавзолей Ясави — OSM way 117854803), `country_lodging.sql`
  (4 места ночлега в Саты и 4 в Туркестане из OSM/Overpass, 2026-11-23; **цен нет** — NULL, бюджет берёт цену по категории и
  честно говорит `lodging_price_assumed`). Всё грузит `make seed` (`load_seed.py`). Без строк настроек планировщик остаётся
  городским: далёкое место из базы тогда — `outside_area`, а не остановка городского дня.

## Контракт JSON (как построено, отклонений от задания нет)

`GET /v1/trips/{id}`:
- каждый день: `{"date", "kind": "regular"|"transfer", "overnight": {"city": {"ru","en"}, "region": "<id региона>", "lat": float,
  "lon": float} | null, "items", "legs"}`. На последнем дне `overnight = null`. У поездок, построенных до Ш-61, — `kind: "regular"`,
  `overnight: null`.
- каждая нога: `"intercity": null | {"mode": "plane|train|bus|car|taxi|tour", "from_city": {"ru","en"}, "to_city": {"ru","en"},
  "approximate": bool, "price_kzt_min": int|null, "price_kzt_max": int|null}`. Для такой ноги `chosen_mode == intercity.mode`,
  `travel_s` = дорога от двери до двери с буфером хаба (`duration_s_max` выбранного варианта), `options` — все варианты
  `intercity.service` в виде `DirectionOption` (`mode` может быть `plane|train|tour`, `group: "intercity"`, `geometry` —
  прямая линия polyline6 для самолёта/поезда/автобуса, дорога Valhalla для машины/такси).
- аддитивно в бюджете: `budget.lodging.stays[]` `{stay, city, region, nights, cost_kzt, price_assumed, no_options, options[]}`
  (в `route_ready` и в GET с опциями), `budget.extra_transport_kzt`; `lodging.cost_kzt` — стоимость всех ночёвок,
  `lodging.needed/nights/options` — домашнего города.
- аддитивно: `brief.dated_wishes`, `brief.stay_wishes`; предупреждения `dated_wish_out_of_range`, `transfer_price_unknown`,
  `no_lodging_found` (detail — город) для точки ночлега; причина `no_transport` в `must_have_unmet` (нет вариантов переезда).
- Не вошло в контракт: `GET /v1/trips/{id}/offline` не получил `kind/overnight/intercity` (iOS-офлайн — отдельно).

## Решения вне SSOT — [предложено]

1. **Домой не возвращаем**: поездка заканчивается в дальнем городе. Если переезд с датой в середине поездки — оставшиеся дни
   «в этом городе» (пустые, ночёвки оплачиваются), выезды из дома после него не планируются (`no_time`). Обратный переезд — позже.
2. **`has_accommodation = true` покрывает только домашний город.** Ночёвки в других точках считаются всегда.
3. **Ночь в пути** (поезд/автобус) не стоит койки; отправление в 20:00 — оценка (расписаний нет, SSOT §16.15).
4. **«По карману»**: переезд, верхняя цена которого ≤ 50% бюджета; среди таких — самый быстрый из самолёт/поезд/автобус; нет — самый
   дешёвый (план честно уйдёт «выше бюджета»). Для выезда по дороге — вариант, рекомендованный `intercity.service` (время + 1 с за ₸).
5. **Дорога без остановок** (вечерний переезд, возврат домой) не показывается ногой, а лежит в `extra_transport_kzt`; день выезда
   на возврат без остановок — пустой `transfer`. Ш-62/iOS может показать это иначе (например, ночлег как остановку).
6. Пожелание далёкого места, которого нет в `outside.py`, остаётся `no_place`/`outside_area`; места страны добавляются в
   каталог `outside.py` + сид.
7. Правка дня с дальним выездом (Ш-38) пересобирает ноги дня обычными городскими, `intercity` ноги теряется (стоимость
   «невидимой» дороги сохраняется в бюджете). Выбор другого способа на ноге (`POST …/mode`) работает.

## Числа, которые нужно подтвердить владельцу (`data/seed/country_planner.sql`, все — оценки команды)

| Ключ | Значение | Смысл |
|---|---|---|
| `local_radius_km` | 60 | ближе — обычный день города (Шымбулак ~25, Чарын ~190) |
| `group_radius_km` | 150 | далёкие места ближе друг к другу — одна поездка (Чарын–Кольсай ~70) |
| `transfer_min_km` | 400 | дальше по прямой — переезд между городами, не выезд на машине |
| `day_trip_max_oneway_h` | 3 | дорога в одну сторону дольше — с ночёвкой (пример владельца ≈3 ч) |
| `transfer_budget_share_pct` | 50 | переезд «по карману» ≤ этой доли бюджета |
| `night_departure_min` | 1200 | ночной поезд/автобус уходит в 20:00 |
| `stay_search_km` | 40 | ночлег не дальше этого от места |
| `max_outing_days` | 4 | выезд не длиннее стольких дней |
| `fallback_road_kmh` | 60 | скорость, только если роутер не отвечает (время помечено оценкой) |

Замечание: Чарын один (≈3 ч по Valhalla) на границе правила 3 ч — вопрос владельцу, считать ли его однодневным.
