## Ревью координатора

- Планировщик (`planner/country.py`) стоит над городским: выезды по направлению (Чарын + Кольсай —
  одна поездка с ночёвкой в Саты), переезд в Туркестан самолётом/поездом/автобусом из Ш-60,
  пожелания с датой не двигаются, дорога расходует часы дня, бюджет — переезды + жильё по точкам.
  Поездки только по Алматы строятся как раньше (регрессионные тесты).
- Чат: места страны — обычные пожелания; `outside_area` — только для мест без данных; промпт v8
  спрашивает «на день или с ночёвкой», «послезавтра» → `dated_wishes`. Живой маршрут — межгородские
  ноги с ценой (миграция 0034).
- iOS: пунктирные дуги «✈ ~2 ч», день переезда, «Ночёвка: Саты», цена переезда «примерно», камера
  на дне переезда охватывает оба города; демо-фразы `shymbulak` / `charyn` / `kolsai` / `turkestan` / `build`.
- Контракт JSON сошёлся: iOS писался по контракту координатора параллельно, сервер собран без отклонений.

## Ждёт владельца

- Настройки планировщика (`data/seed/country_planner.sql`): ночёвка, если дорога в одну сторону > 3 ч
  (Чарын ~3 ч — на границе); переезд дальше 400 км; выезды группируются в радиусе 150 км; выезд не
  длиннее 4 дней; переезд «по карману» — верхняя цена ≤ 50 % бюджета.
- Цены жилья в Саты и Туркестане неизвестны — берётся цена по категории с пометкой.
- [предложено]: после переезда домой не возвращаем; «жильё есть» — только домашний город; ночь в
  поезде не оплачивается как койка; нога Кольсай → Туркестан идёт одной ногой через Алматы.
- Гостевой промпт (v4) ещё упоминает `outside_area` для дальних мест.
