# Ревью Ш-47 (iOS) — загруженность: «я здесь», отчёт, блок в карточке

## Что сделано

- **Блок статистики** (`Features/Crowd/CrowdSection.swift`) в «Обзоре» карточки места показывается только если сервер прислал `crowd` (не `null`): «Сейчас людно / нормально / пусто» (если `now` пуст — «На этот час данных пока нет»), столбики по часам сегодняшнего дня, число отчётов. Для места без данных (`crowd: null`) блока нет, ничего не придумывается.
- **Действия** — всегда на карточке, потому что без них данные не появятся: «Я здесь» (`POST /v1/places/{id}/checkin`) и «Людно / Нормально / Пусто» (`POST …/crowd` с `level` `busy`/`normal`/`empty`). Каждое отправляет ТЕКУЩЕЕ местоположение: один фикс по разрешению «при использовании» (`LocationProviding`, без фоновой геопозиции), геопозиция в запросе — `lat`, `lon`.
- **Ответы**: `recorded: true` — «Спасибо»; `recorded: false` — «Вы только что отмечались / уже сообщали»; 422 `too_far_from_place` — «Нужно быть не дальше 200 м»; 429 — «Повторите через N мин» (по `Retry-After`) или «позже»; отказ в геопозиции — подсказка и кнопка «Настройки»; нет фикса и сбой — сообщения. Без геопозиции запрос не отправляется.
- Гость при нажатии получает окно входа (серверу нужен человек: 401 без токена).

- Юнит (`PlaceActionsTests`): тело запроса (`lat`, `lon`, `level`), `recorded: false`, 422, 429 с `Retry-After`, 500, нет геопозиции → нет запроса.

## Не сделано

- Радиус 200 м проверяет только сервер; клиент заранее расстояние не считает (в заглушке посчитано для теста).
- Нет напоминания «вы всё ещё здесь», фоновых проверок и показа загруженности на карте/в маршруте (§7.3 — только карточка).
- Не проверено на устройстве (диалог разрешения, «Не разрешать»).
