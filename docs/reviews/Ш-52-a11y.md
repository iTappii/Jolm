# Ш-52 (доступность) — полная карта маршрута, «Как добраться», мероприятия, бронирование, готовые маршруты

Ветка `sh-52-a11y` (от `sh-22-24-auth`, `6a07bcd`). Объём: только экраны своей зоны. Остальные экраны Ш-52
(политики, App Privacy, скриншоты App Store и т. д.) не затрагивались.

## Что сделано

Общее (аддитивно, существующие токены не менялись):
- `Core/Design/AdaptiveLayout.swift`: `AdaptiveStack` (строка → столбец при размерах Dynamic Type «accessibility»),
  `JolTarget.minimum = 44`, `Text.spoken([...])` — склейка фразы для VoiceOver.
- Новые строки в `Localizable.xcstrings` (RU): «Loading», «Page %lld of %lld», подсказки VoiceOver
  («Opens the budget», «Opens the place card», «Shows the ways to get there», «Uses this way for the leg»,
  «Shows this way on the map»). Чужие ключи не менялись.

Тёмная тема: все экраны зоны используют токены `JolColor` (динамические light/dark); жёстко заданных светлых цветов в
SwiftUI-коде зоны нет. Стиль карты переключается на `jol-dark` через `AppConfig.mapStyleURL(dark:)` в `MapScreen`
(уже было). Слои карты (маркеры с белой обводкой и чёрным номером на оранжевом) читаются на тёмной карте — не менялись.

По экранам:
- **Полная карта маршрута** (`TripMapOverlay`, `TripDayListView`, `TripLegSheet`): верхняя панель и чипы дней — не
  выше 44 pt, потолок Dynamic Type `accessibility1` для верхней панели (иначе она съедает карту), атрибуция OSM
  скрыта от VoiceOver и ограничена `xxxLarge`. На AX-размерах панель выше (70 % экрана вместо 45 %) и вся прокручивается
  вместе с заголовком; заголовок дня/чип бюджета складываются в столбец. Чип бюджета: «Бюджет, 120 000 ₸, превышен»,
  подсказка. Строки остановок на AX-размерах раскладываются в столбец (бейдж, название, подпись, кнопка «убрать»),
  кнопка «убрать» 44×44 вместо 36, значение — название места. Строка перехода читается целиком:
  «Автобус, 13 мин, ≈120 ₸[, прибытие с опозданием]»; иконки скрыты. Лист способов: строки читаются «режим, время, цена,
  расстояние[, рекомендуем]», выбранная — с трейтом selected.
- **Как добраться** (`DirectionsPanel*`, правки минимальные): кнопка назад 44×44 (`fixedSize`), текстовые кнопки
  («From map centre», «Settings», «Retry») с областью нажатия ≥ 44, строка «откуда» и уведомление складываются в
  столбец, чипы режимов ≥ 44 pt и читаются «Пешком, 12 мин»; страница: «Пешком, страница 1 из 3» (заголовок);
  вариант читается «Пешком, 12 мин, Будете в 14:35, Бесплатно, Оптимальный[, загруженность]»; индикатор загрузки
  подписан; иконки скрыты.
- **Мероприятие** (`EventCardSheet`): строка «Event + Ad» складывается в столбец; кнопка места ≥ 44 с подсказкой.
- **Бронирование** (`BookingSheet`): на AX-размерах сегменты заменены меню (иначе обрезаются), экран результата
  прокручивается, декоративная иконка статуса скрыта, кнопка «Check the status» ≥ 44.
- **Готовые маршруты** (`CuratedRoutesViews`): закрытие плашки 32 → 44, номера в чипах масштабируются
  (`ScaledMetric`), заголовок плашки до 3 строк на AX, подсказки чипов, «Retry» ≥ 44.
- `TripBudgetSheet` — не правился: на скриншоте (тёмная, AXXXL) текст переносится, сумма и «Over budget» читаемы;
  нижняя часть таблицы статей не просмотрена (лист прокручивается).
- **Пины/кластеры карты**: визуально не менялись (отрисовка MapLibre, не SwiftUI); см. «Замечания».

## Замечания (по важности)

1. **Карточка места вне зоны** (`PlaceCard*`): на AX-размерах закреплённые кнопки «Маршрут» / «В избранное» ломают
   слова («Rout-e», «Add to fa-vorites»), налезают друг на друга, а лист в треть экрана показывает только заголовок.
   Это видно на скриншоте `directions-*-axxxl.png`. Нужен проход там (складывать кнопки в столбец, больше деталь).
2. Атрибуция «© OpenStreetMap» и «Shall we start the journey?» на домашнем экране (`HomeScreen`, вне зоны) на AX
   занимают много места и перекрывают карту — ограничить размер, как сделано в `TripMapOverlay`.
3. VoiceOver не проверялся на устройстве/Accessibility Inspector — проверены только подписи/трейты через XCUITest.
   Страницы «Как добраться» листаются `accessibilityAdjustableAction` на контейнере с `.contain` — работоспособность
   жеста «листать» вживую не подтверждена; чипы режимов доступны как кнопки и работают как запасной путь.
4. Тёмная карта проверялась только на заглушке стиля (офлайн, светлая); `jol-dark.json` с реальным сервером — вручную.
5. Системные кнопки панели навигации («Done», «Cancel») имеют стандартные 36 pt видимой области — оставлены как есть.
6. Пины/кластеры/номера на карте не масштабируются под Dynamic Type (слои MapLibre) и не озвучиваются VoiceOver
   (озвучивается список остановок в панели).
