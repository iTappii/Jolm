# Ревью Ш-45 — автофильтр и модерация

## Автофильтр (`server/app/submissions/autofilter.py`)

Правила без LLM, выполняются синхронно при `POST /v1/submissions`. Любое срабатывание даёт
`rejected_auto`: ответ 201 с `reason_codes`, ничего не публикуется, бонуса нет (бонусы — Ш-46),
файл фото ставится в очередь на удаление.

| Код | Правило |
|---|---|
| `too_short` | текст отзыва короче 10 символов (одна оценка без текста допустима) |
| `no_letters` | в тексте отзыва нет букв |
| `repeated_text` | один символ 8+ раз подряд или одно слово — 60% и больше слов (от 5 слов) |
| `contains_link` | URL, домен, `t.me`/`wa.me`, e-mail |
| `contains_contact` | номер телефона |
| `profanity` | слово из `profanity.txt` (RU/EN/KZ): префиксы и точные слова, нижний регистр, ё→е, повторы букв схлопываются |
| `duplicate_text` | тот же текст отзыва уже опубликован для места, либо этот человек уже слал его за 30 дней |
| `duplicate_photo` | те же байты (sha256) уже опубликованы или ждут проверки |
| `rejected_photo` | те же байты уже отклонил модератор |
| `implausible_price` | вход: больше 200 000 ₸ или в 10 раз выше известной цены места, либо взрослый/иностранный/резидентский билет в 10 раз ниже известной; блюдо вне 50–100 000 ₸; проезд выше 5 000 ₸ |

Текстовые правила применяются ко всем строкам, которые пишет человек (текст отзыва, названия и
описания блюд, подпись к фото, остановка/направление/заметка, заметка к цене).

## Модерация (админка `/admin/moderation`)

Очередь: `published_pending_review`, старые первыми (50 строк, всего показано). Кнопки
«Одобрить» / «Отклонить» — формы с CSRF-токеном сессии, вход администратора обязателен.
Решение принимается один раз (`UPDATE ... WHERE status = 'published_pending_review'`); повторное
нажатие даёт «уже решено». Записываются `moderator_id` и `decided_at`.

- Одобрение: `approved` (пометка «проверится позже» пропадает). Меню применяется к месту
  (`place_menu`, источник `user`), цена `adult` — к `entry_price_kzt` с записью в `manual_override`,
  чтобы импортёр OSM её не затёр; данные о транспорте только помечаются.
- Отклонение: `rejected`; отзыв исчезает из списка и сводки; фото получает
  `place_photos.status = 'rejected'` (с карточки пропадает), файл удаляется задачей.

Почему меню и цены применяются только после одобрения, а отзывы и фото видны сразу: SSOT §10.2
велит публиковать прошедшее фильтр сразу, но меню и цены перезаписывают факты о месте, а отзыв и
фото принадлежат голосу пользователя; решение зафиксировано в `docs/adr/0003-open-defaults.md`.

## Не сделано и ограничения

- **Классификация LLM** (опционально по плану) не делалась: правила не поймают связный, правдоподобный
  по виду спам или фальшивую похвалу. Это работа очереди модерации.
- **Мат-лист — зачаток** на ~50 записей. Его нужно расширять с носителями языка, особенно
  казахскую часть; обход (пробелы между буквами, замена латиницей и цифрами) не ловится.
  Префиксы дают ложные срабатывания на редких словах; список обновляется без миграции.
- Нет жалоб пользователей на опубликованное, нет причин и комментария модератора к отклонению,
  нет пагинации очереди (первые 50) и фильтра по типу.
- Повторной проверки по более строгим правилам уже опубликованного нет.
- Бонусы не начисляются (Ш-46): статус `approved` и `decided_at` — то, от чего Ш-46 будет считать.
- Веб-интерфейс очереди проверен только тестами рендера и POST, в браузере не открывался.
