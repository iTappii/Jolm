# Ревью Ш-42 (серверная часть) — скачанный маршрут

`GET /v1/trips/{id}/offline` отдаёт всё, что нужно приложению без сети: версию, дни со временем,
места и для каждого перехода выбранный вид транспорта с геометрией. iOS-часть не делалась.

## Ответ

Заголовки: `ETag: "v<version>-<язык>"`, `Cache-Control: private, no-cache`,
`Vary: Accept-Language`. Тело (языки по `Accept-Language`, как в остальном API):

```json
{"trip_id": "<uuid>", "version": 1, "locale": "ru", "timezone": "Asia/Almaty",
 "geometry_encoding": "polyline6", "start_date": "2026-12-05", "end_date": "2026-12-07",
 "budget_kzt": 900000, "total_cost_kzt": 118000,
 "days": [{"date": "2026-12-05",
           "items": [{"id", "ord", "kind", "meal", "place_id", "starts_at", "ends_at",
                      "visit_min", "must_have", "est_cost_kzt"}],
           "legs": [{"id", "from_item_id", "to_item_id", "depart_at", "travel_s", "estimated",
                     "mode", "cost_kzt", "distance_m", "geometry"}]}],
 "places": {"<place_id>": {"name", "name_lang", "names": {"ru", "en", "kk"}, "category",
                           "category_name", "lat", "lon", "address",
                           "hours": [{"weekday": 0, "intervals": [{"opens": "10:00",
                                                                    "closes": "18:00"}]}],
                           "photo_url": null}}}
```

Времена в Asia/Almaty (+05:00). `places` — каждое место один раз; названия и адрес по
языку с запасным языком, `names` — все три языка. `mode` / `geometry` — выбранный вид перехода и
путь его лучшего варианта (polyline6); `null`, если вид не вычислен. `photo_url` =
`MEDIA_BASE_URL/<storage_key>` первого одобренного фото; пока `MEDIA_BASE_URL` пуст (Ш-44) — `null`.
Настройка `media_base_url` добавлена в `app/config.py`.

## ETag

`If-None-Match` (`*`, один или несколько тегов, слабое сравнение) совпал -> `304` без тела, с
`ETag`. Проверка идёт после авторизации и владельца: чужая поездка даёт `404`, а не `304`.
Любая правка (удаление, замена, выбор транспорта, выбор бюджета, принятие предложения) растит
`version`, и тег перестаёт совпадать. Язык входит в тег: другой язык — другое представление.

## Проверки

`server/tests/test_trips_offline.py` — 4 теста: форма и совпадение с `GET /v1/trips/{id}`
(время, переходы, геометрия выбранного вида), имена RU/EN, адрес, часы, `photo_url` до и после
`MEDIA_BASE_URL`, ETag/304 (варианты заголовка, смена языка, рост версии после выбора вида
транспорта), 401 / 404 для чужой и несуществующей поездки, 422 для не-UUID.

## Не проверено / ограничения

- Изменение данных места без новой версии маршрута (часы, адрес, фото) в ETag не отражается;
  клиент обновляет копию при смене версии.
- Жильё в копию не входит (в плане его нет как остановки).
- Размер ответа не измерялся на длинной поездке (геометрии — основной объём); gzip на уровне
  прокси.
- iOS: сохранение на устройство и работа в авиарежиме — отдельная часть Ш-42, не сделана.
