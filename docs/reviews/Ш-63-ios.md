# Ш-63 (iOS) — камера живого маршрута и карты поездки

## Что сделано

- `ios/Jol/Features/Map/MapCamera.swift`: добавлен `CameraFit` — чистая математика подгонки камеры без MapLibre:
  - `plan(for:singleZoom:)` — одна точка (или бокс меньше ~55 м) центрируется с фиксированным зумом, иначе — подгонка по границам;
  - `liveRoutePadding(mapHeight:targetInset:currentInset:)` — отступы так, чтобы маршрут оказался над карточкой чата
    (с поправкой на ещё не доанимированный `contentInset`; при поднятой клавиатуре — узкая полоса, отступы меньше);
  - константы: `singleStopZoom = 15` (карта поездки), `liveSingleStopZoom = 14` (живой маршрут).
- `MapCoordinator+Chat.swift` (`fitLiveRoute`): использует `CameraFit`. Перепосадка камеры при сворачивании/разворачивании
  чата и появлении/скрытии клавиатуры уже срабатывала по смене `bottomInset` (`applyLiveRoute`, `LiveRouteFit.inset`);
  математика вынесена и покрыта тестами, поведение сохранено.
- `MapCoordinator+Trip.swift` (`applyTrip`): день с одной остановкой больше не приближается сверх зума 15
  (раньше `setVisibleCoordinates` с одной точкой уходил в максимальный зум). Подгонка нескольких остановок не менялась.
- Тесты: `ios/JolTests/CameraFitTests.swift` (7 тестов): нет точек, одна точка, совпадающие точки, несколько точек,
  отступы при открытии/сворачивании карточки, узкая полоса с клавиатурой.

Стили, цвета, шрифты, метки доступности не трогались.
