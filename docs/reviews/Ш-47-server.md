# Ш-47. Загруженность мест на сервере

Пользователь с активной сессией может отметить посещение или сообщить, сколько людей в месте. Карточка и планировщик получают статистику из одних и тех же отчётов. Источник данных остаётся рабочим допущением из SSOT §16.5.

## Запись

- `POST /v1/places/{id}/checkin` принимает `lat` и `lon`. Для `POST /v1/places/{id}/crowd` дополнительно нужен `level` со значением `empty`, `normal` или `busy`.
- PostGIS проверяет расстояние до активного места. В пределах 200 метров сервер отвечает `{"recorded": true, "distance_m": 55}`. При превышении радиуса возвращает 422. В базе остаются расстояние, место и время. Отправленные координаты используются только при проверке.
- Повтор отметки за 30 минут или отчёта за два часа возвращает `recorded: false`. Лимит новых записей на человека составляет 40 за скользящие сутки. При исчерпании квоты заголовок `Retry-After` показывает, когда освободится первая запись. Транзакционная блокировка пользователя сериализует параллельные отправки.
- Удаление аккаунта удаляет его отметки и отчёты. При объединении дублей OSM исходные записи переходят на сохранившееся место.

## Чтение

Ежечасная задача `crowd.aggregate` собирает отчёты за 60 дней по местному дню недели и часу в Алматы. Вес сообщения за две недели уменьшается вдвое. Отметки «Я здесь» сохраняются отдельно по типу записи и в расчёт уровня не входят.

В `GET /v1/places/{id}` поле `crowd` равно `null`, пока для места меньше пяти отчётов. Для показа конкретного часа нужны два отчёта за этот час недели. Поле `now` может быть пустым даже при наличии прогноза на другие часы сегодня. При построении поездки планировщик использует среднее по дневным часам (09:00–21:00) при наличии пяти дневных отчётов. Пользователь, предпочитающий уединение, получит шумное место ниже в подборке.

## Проверка

На PostgreSQL с PostGIS прошли девять тестов в `server/tests/test_crowd.py` и сценарий объединения мест в `server/tests/test_osm_pipeline.py`. Они покрывают географический радиус, права, квоту и повтор при полной квоте, удаление аккаунта, местное время, уменьшение веса, пороги для карточки и реальный вызов сборки маршрута.

Интерфейс отправки и отображения отчётов на iOS остаётся частью Ш-47. Радиус и статистические пороги заданы константами для первой версии.
