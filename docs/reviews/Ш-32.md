# Ш-32. iOS: чат, граф, живая карта

Интерфейс чата с планировщиком поездок: стриминг текста через SSE, одноветвенный граф тезисов, живая синхронизация кандидатов с картой и переход к готовому маршруту.

## Реализация

- **Стриминг и протокол:** `ChatService` подключается к `/v1/chat/{session_id}/events` через `SSEClient` с заголовком `X-Install-ID`. Поддерживаются все события протокола: `text_delta`, `graph_node`, `brief_updated`, `map_places`, `done`, `error`.
- **Одноветвенный граф тезисов (`ChatGraphView`):** узлы добавляются по мере получения `graph_node` с плавной анимацией появления. Завершающий узел «Маршрут готов» (`graph-final`) содержит кнопку «Посмотреть маршрут» (`chat-open-route`) с количеством дней.
- **Интерактивные предложения:** карточки правок с кнопками «Принять» / «Отклонить» (`proposal-accept`, `proposal-decline`). После выбора кнопки скрываются, статус фиксируется.
- **Сворачиваемый чат (`ChatPanel`):** переключение между полным экраном и свёрнутой плашкой внизу (`chat-collapsed-bar`). При свёрнутом чате стриминг продолжается, в плашке отображается индикатор набора текста.
- **Живая карта (`MapCoordinator+Chat`):** пины кандидатов (`map_places`) появляются на карте синхронно с ходом беседы, центрируя обзор.
- **Шит маршрута по дням (`TripDaysSheet`):** по нажатию на итоговый узел графа открывается разбивка маршрута по дням со списком мест и кнопкой закрытия.
- **История и боковая панель (`SidebarPanel`):** список недавних чатов, возможность начать новый чат (`sidebar-new-chat`), сохранение черновика при гейте входа.
- **Обработка ошибок и перегрузки:** 409 `chat_busy` выводится инлайн с кнопкой «Повторить» (`chat-retry`); 429 с `Retry-After` запускает обратный отсчёт.

## Проверка

- 121 юнит-тест в `JolTests` (включая `ChatModelTests`, `ChatReductionTests`) прошли успешно.
- 10 UI-тестов в `ChatUITests` (рост графа, анимация пинов, сворачивание чата, 409 busy + retry, отказ от предложения, русский интерфейс, смена языка на лету) прошли успешно на симуляторе iPhone 17 (iOS 27.2).
