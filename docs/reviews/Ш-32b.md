# Ревью Ш-32b — узлы графа = ответы пользователя (цепочка вместо кольца)

Шаг менялся по ходу работы четыре раза по решениям владельца (2026-11-21): сначала подписи значений на кольце, затем кольцо поменьше в правом верхнем углу карточки, затем новая раскладка главного экрана, в конце — **кольцо отменено, граф стал цепочкой** с прямыми рёбрами. Ниже итоговое состояние.

## Что сделано

### Сервер (порядок заполнения, восстановление)
- **Миграция `db/migrations/0027_brief_filled_order.sql`**: `trip_briefs.filled_order jsonb NOT NULL DEFAULT '[]'` — в порядке ответов пользователя: имя поля брифа или `must_haves:<пункт>` (на каждое обязательное пожелание отдельная запись). Колонка не содержит ничего, чего нет в брифе, и удаляется каскадом вместе с чатом, поэтому удаление аккаунта её покрывает отдельно не нужно.
- `chat/brief.py`: `fill_entries` (записи одного обновления: изменённые поля, для `must_haves` — по записи на каждый добавленный пункт; удаление ничего не добавляет) и `merge_filled_order` (повторный ответ держит своё место). `chat/store.py`: `get_filled_order`, `record_filled_order` (после `lock_brief`, чтобы параллельные обновления не теряли записи). `chat/api.py`: инструмент `update_trip_brief` пишет порядок; `GET /v1/chats/{id}` отдаёт `brief.filled_order`.

### iOS (цепочка, `Features/Chat/`)
- **`ChainGeometry`** (чистая математика, бывший `RingGeometry`): узлы слева направо с шагом 66 pt, чётные чуть выше средней линии, нечётные ниже (амплитуда 9 pt); пока цепочка помещается, она центрируется (1 узел — по центру, 2 — слева и справа, N — вся цепочка по центру), иначе левый край фиксируется, а полоса прокручивается. Подпись — над «верхним» узлом и под «нижним», поэтому подписи соседей не пересекаются. **Рёбра — прямые отрезки** от края узла до края узла (без кривых). Высота полосы 66 pt.
- **`ChatGraphView`** — полоса сразу под шапкой (название + «свернуть») на всю ширину карточки, над сообщениями. Новый узел въезжает справа, остальные плавно смещаются к новому центру (позиции анимируются по числу узлов); при переполнении полоса прокручивается к новому узлу. После `route_ready` в конец добавляется финишный узел (флажок). Узлы — кнопки с иконкой (календарь, купюра, кровать, звезда, искры, пешеход, люди); значение стоит рядом, длинное обрезается (18 символов), полное значение — в accessibility-метке узла и по тапу в плашке. Кольцо и весь код кольца удалены. `ChatChainFooter` (под полосой): плашка с полным значением выбранного узла и кнопка «Открыть полную карту» — появляется вместе с финишным узлом.
- **`ChainNodes`** (бывший `RingNodes`): бриф → узлы в порядке ответов; `ChainLabels` — значения («5 дней», «200 000 ₸», «жильё есть», «восточная кухня»; RU/EN). Изменение ответа меняет подпись существующего узла, нового узла нет. При повторном открытии чата цепочка восстанавливается из `brief.filled_order` (для сервера без порядка — канонический порядок полей).
- **`ChatPanel`**: убрана строка `BriefChips` (граф показывает те же значения); цепочка в шапке карточки. Идентификаторы переименованы: `chat-chain` (значение `building`/`ready`), `graph-node-N`, `graph-chain-finish`, `graph-node-detail`.
- **`HomeScreen`** (решения владельца по раскладке): кнопка профиля (`open-profile-menu`) — в правом верхнем углу, зеркально кнопке боковой панели; свёрнутая строка чата занимает нижний ряд целиком; развёрнутая карточка опущена почти до самого низа (`conversationFraction` 0.68, `mapBottomInset` соответственно), верх остаётся там же; над карточкой зарезервировано место под верхние кнопки (60 pt), поэтому при клавиатуре карточка не наезжает на них; подпись «© OpenStreetMap contributors» прибита к низу экрана вне оверлея, который следует за клавиатурой (`ignoresSafeArea(.keyboard)`): клавиатура наезжает на неё, она не поднимается.
- Фикстуры: удалены `chat-ring*.sse`, добавлены `chat-dlg-0…7.sse` (диалог «дни → бюджет → жильё → пожелание → смена бюджета → готово → ещё ответы»; `#dlgN` в `UITestChatStub`).
- Xcode-проект пересобран `xcodegen generate`.
- **Верхняя граница переписки** (замечание координатора по скриншотам): у прокрутки `ChatTranscriptView` добавлена маска-градиент 18 pt сверху (прозрачный → непрозрачный): прокрученные вверх сообщения растворяются под полосой, а не обрезаются посередине строки; маска работает по альфа-каналу, поэтому одинакова в светлой и тёмной теме. Между кнопкой «Открыть полную карту» и первым сообщением добавлен отступ.

## Замечания

1. (средне) Полный прогон UI-тестов в одном заходе не зелёный из-за подвисаний симулятора (`PlaceActionsUITests`) и одного нестабильного теста; перепроверено по частям. Повторить целиком в начале следующей сессии.
2. (средне) Старые ошибки тестов цепочки были моими: проверка позиции по первому сообщению (кадр прокрученного сообщения выходит за область — теперь по `chat-transcript`) и автопрокрутка (теперь после короткой паузы, пока раскладка догоняет число узлов).
3. (низко) Длинные значения обрезаны «…» («Have accommod…» при 10 pt в боксе 96 pt); полное значение — в метке и плашке по тапу.
4. (низко) Нативная кнопка «i» MapLibre внизу справа теперь рядом с нашей подписью OSM (на скриншотах не видна); не проверялось, не перекрываются ли они на устройстве.
5. (низко) При прокрутке полосы крайние подписи обрезаются краем карточки — это поведение прокрутки.
6. Не проверено: VoiceOver вручную, Dynamic Type крупнее стандартного, Reduce Motion, поведение на iPhone с узким экраном.
