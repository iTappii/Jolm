# Ревью Ш-60 — межгородские переезды

Ветка `sh-60`. SSOT §5.4 п. 5, §16.15 (источники расписаний не выбраны, `# OPEN(SSOT §16.15)`).

## Что сделано

- Миграция `db/migrations/0032_intercity.sql`: таблицы `intercity_hubs`, `intercity_links`,
  `intercity_settings`; в `transport_tariffs` добавлен режим `taxi_intercity` (проверки таблицы
  пересозданы с именами, история остаётся append-only).
- Сид-данные `data/seed/intercity.sql` (грузится `make seed` через `load_seed.py`) и строка тарифа
  `taxi_intercity` в `data/seed/transport_tariffs.sql`. Цифры — только в данных, не в коде.
- `GET /v1/intercity/options` (`server/app/intercity/`), публичный, лимит 60 запросов в минуту на адрес
  (как у геокодера, общий счётчик в БД).
- Межгородские тарифы в `POST /v1/directions`: от `min_distance_km` по дороге такси считается по
  `taxi_intercity` (500 ₸ + 90 ₸/км, без минут и без городского множителя пробок), своя машина — топливо
  по км из `intercity_settings` (расход и цена литра). Нет настроек в БД — прежние городские тарифы.
- Админка тарифов знает режим «Такси, межгород».

## Модель данных

- `intercity_hubs`: `id`, `kind` (airport / rail / bus / city), названия RU/EN, город, `code` (IATA),
  `location` (точка), `catchment_km` — на каком расстоянии от узла он обслуживает точку.
- `intercity_links`: пара узлов + `mode` (plane / train / bus / tour), время поездки мин–макс (минуты),
  цена мин–макс (₸ на человека; может быть NULL = цена неизвестна), `transfers`, `buffer_min` (приезд до
  отправления), `schedule_days` (дни недели ISO, NULL = не известно), `departure_hint`, заметки RU/EN,
  `source`, `source_url`, `as_of`, `approximate`. Одна строка — одно направление; уникально
  (откуда, куда, режим).
- `intercity_settings`: `fuel_l_per_100km` 9, `fuel_price_kzt_per_l` 220, `min_distance_km` 50,
  `max_road_km` 1500, у каждого `source`, `as_of`.
- Машина и такси — не в таблице связей: время и расстояние берутся из Valhalla по запросу.

## Формат API

`GET /v1/intercity/options?from_lat&from_lon&to_lat&to_lon[&date=YYYY-MM-DD]`, язык имён и заметок —
`Accept-Language` (ru / en). Без авторизации. Точка вне всех регионов или неверные параметры — 422;
лимит — 429 с `Retry-After`; БД или Valhalla недоступны — 503. Если расстояние между точками меньше
`min_distance_km` — `options: []` (это не межгород, годится обычный `/v1/directions`).

```
{ "from": {lat, lon, region}, "to": {lat, lon, region}, "date": "2026-12-01" | null,
  "options": [ {
    "mode": "plane|train|bus|car|taxi|tour",
    "duration_s", "duration_s_min", "duration_s_max",   // от двери до двери (без ожидания рейса)
    "cost_kzt_min", "cost_kzt_max",                     // всего, включая такси до/от узла; null если цена неизвестна
    "price_basis": "person" | "vehicle",
    "approximate", "source", "source_url", "as_of", "transfers",
    "schedule": {"days": [1..7] | null, "departure_hint", "runs_on_date": true|false|null} | null,
    "note", "geometry" (polyline6, только car/taxi), "distance_m" (car/taxi),
    "legs": [ {"type": "access|wait|main|egress", "mode", "from_name", "to_name",
               "duration_s_min", "duration_s_max", "distance_m", "cost_kzt_min", "cost_kzt_max"} ],
    "recommended": bool } ] }
```
Варианты отсортированы по времени; `recommended` — один (время + 1 с за тенге, как в directions). По
режиму выбирается самая быстрая пара узлов. Подъезд и отъезд от узла — такси по городскому тарифу
(Valhalla), для тура отъезд от Саты входит в тур. `runs_on_date` не угадывается: `null`, если дни
недели неизвестны. iOS-часть — в Ш-62.

## Тарифы

Такси на 200 км: городской тариф (400 + 30 ₸/мин + 100 ₸/км, × пробки до 1,6) давал 29–36 тыс. ₸;
межгородской (500 + 90 ₸/км, без минут и множителя) — около 19 тыс. ₸. Порог — `min_distance_km`
по длине маршрута. Планировщик и живой маршрут `get_directions` вызывают без межгородских параметров —
их поведение не менялось (Ш-61 решит, как считать переезды в плане).
