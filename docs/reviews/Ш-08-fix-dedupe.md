## Что сделано

- Путь, являющийся внешним контуром импортированного отношения того же класса, не импортируется
  (Ботанический сад: остаётся отношение 3048271).
- Пары «точка + путь/точка» одного заведения: одно нормализованное название, один класс, ≤ 50 м,
  хотя бы один — точка. Победитель — путь/отношение; недостающие теги (названия, адрес, часы,
  сайт, кухня) берутся у удалённого. Филиалы сетей дальше 50 м и пары «путь + путь» не сливаются.
- `data/osm/merge.py` — единое слияние строк базы без потери данных (часы, фото, меню, места
  в маршрутах, мероприятия, ручные поля, `manual_override`); используется и импортом OSM,
  и импортом подборки.
- Dev-база: 2762 → 2738 мест (1 контур + 23 дубля). Подборка перепривязана (Ботанический сад,
  памятник Райымбек батыру).
- Тесты на маленьком `.osm`-фикстуре: полный конвейер, идемпотентность, точка внутри полигона,
  слияние без потерь, правила «далеко / другой класс — не трогать».
