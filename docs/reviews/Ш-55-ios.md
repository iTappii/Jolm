# Ревью Ш-55 (iOS): замена места, «все дни», «Мои брони», доступность боковой панели и профиля

Ветка `sh-55-ios`. Серверные эндпоинты Ш-55 делает другой агент: iOS собран по контракту плана Ф19 и проверен на заглушках
(`-JolStubAPI`), с настоящим сервером не проверялся.

## Что сделано

1. **Ш-37, замена места.** В строке остановки рядом с «убрать» — кнопка «Заменить место» (44 pt). Лист
   `TripReplaceSheet`: `GET /v1/trips/{id}/items/{item_id}/alternatives` → название, категория, цена (если есть),
   расстояние; тап → `POST …/replace {"place_id", "force"}`. Лист закрывается, план перечитывается, `editRevision` растёт
   (чат обновит пины). Ошибки: 409 `must_have` → вопрос «Заменить то, что вы просили?» и повтор с `force`; 409
   `no_replacement` → сообщение в листе, лист остаётся; 404/409 (план изменился) → лист закрывается, план перечитывается;
   нет сети → баннер. Загрузка альтернатив: «Загрузка», «Не удалось загрузить» + «Повторить», пустой список.
2. **Ш-37, «Все дни».** Чип «Все дни» перед «День 1» (если дней больше одного). Список сгруппирован по дням (заголовок дня
   цветом дня), замена/удаление работают из него. `TripMapModel.stops/lines` отдают остановки и линии всех дней, у каждой
   `colorHex` дня; камера охватывает всё. Идентификаторы строк в этом виде: `trip-stop-d{день}-{номер}`.
3. **Ш-49, «Мои брони».** Профиль → «Мои брони» (только вошедшим): список (место, вид, дата/время по Алматы, людей, статус
   значком и словом), деталь, «Отменить бронь» с подтверждением → `POST /v1/bookings/{id}/cancel`. 409 `not_cancellable`
   объясняется («уже отменена или прошла, свяжитесь с заведением»), бронь перечитывается; нет сети — отдельный текст.
   Кнопка есть только у `pending`/`confirmed`. Постраничная подгрузка по `next_cursor`.
4. **Ш-52 для этих экранов.** Боковая панель: цели ≥ 44 pt (закрыть, скачать, строки), на AX панель шире и прокручивается
   целиком, строка поездки — иконка слева, даты и «3 дня» столбцом, панель `isModal`, заголовки — header. Профиль: «Войти»,
   аватар, галочка языка — `brandText`; строки ≥ 44 pt; индикатор «Удаляем аккаунт…» во время удаления. Баланс бонусов —
   `brandText`. Новые экраны: статусы не только цветом, `AdaptiveStack`, VoiceOver-подписи.
5. **Старые «тёмные» UI-тесты.** `PlacesUITests.launch(dark:)` теперь включает тему через `XCUIDevice.shared.appearance`
   (в tearDown — светлая); аргумент `-UIUserInterfaceStyle` убран (других мест нет).

## Замечания

1. **Важно — нужна правка в `Map*`** (чужая зона): цвета дней на карте в «всех днях». `TripMapStop`/`TripMapLine` уже несут
   `colorHex`, но `MapCoordinator+Trip.applyTrip` красит всё одним `tripColor`. Нужно: в атрибуты фич добавить
   `"color": UIColor(hex: colorHex)` (строкой `#RRGGBB`), а у слоёв `tripLine`, `tripDashed`, `tripStop` взять цвет из
   атрибута: `NSExpression(forKeyPath: "color")` для `lineColor`/`circleStrokeColor`. Пока карта в этом виде рисует всё
   оранжевым (в списке цвета дней правильные).
2. Серверный контракт `alternatives`/`cancel` не проверен на живом сервере; `replace` отвечает как `remove` (читаются
   `version`, `changed_days`, `dropped`).
3. На iOS 27 `confirmationDialog` — поповер без кнопки «Отмена» (закрывается тапом вне). UI-тесты это учитывают.
4. Системные кнопки панели навигации («Готово», «Назад») ниже 44 pt по рамке — это стандартный элемент, не менялся.
5. Проверка VoiceOver на устройстве не проводилась (только метки и размеры в UI-тестах).
