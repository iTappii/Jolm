# Ревью Ш-70 (сервер) — рейтинг, «сегодня», адрес и логотип места

Серверная часть шага «Заведения на карте и карточка». iOS (значки на карте, карточка, звёзды в форме
отзыва) делает другой агент по тому же контракту. Расстояние до пользователя считается на устройстве.

## Что сделано

- Миграция `0039_place_logo.sql`: `places.logo_key`, `places.logo_source` (`partner` | `team`),
  CHECK «ключ и источник заданы вместе». Ничего не импортируется из OSM и брендов; везде `null`,
  пока партнёр или команда не загрузят логотип с правом показа.
- Оценка в отзыве уже была: `ReviewPayload.rating` (1–5) из Ш-44 (`app/submissions/schemas.py`),
  вне диапазона — 422, хранится в `submissions.payload`. Дубль не делали.
- Рейтинг: среднее и число по отзывам со статусами `published_pending_review` и `approved`
  (те же, что в списке отзывов). Исключены `rejected_auto`, `rejected`, `pending_filter`. Отзыв,
  ждущий модератора, считается сразу: SSOT §10.2 показывает его всем «проверится позже». Округление
  до 1 знака (`round`), `null` при нуле отзывов. Один пакетный запрос `RATINGS_BY_PLACES`
  (`place_id = ANY(...)`, индекс `submissions_place_published`).
- «Сегодня»: `service.today_block(hours, now, tz)` по календарному дню в часовом поясе региона места
  (`service.region_tz(lat, lon)`: регион, чья граница накрывает точку, иначе регион по умолчанию).
  Тот же разбор часов, что у `open_now` и планировщика (`is_open_now` получил параметр `tz`).
- Адрес: `address` в карточке уже был; добавлен в пины.

## Контракт как построен

`GET /v1/places/{id}` и каждый элемент `GET /v1/places` (в том числе `format=geojson`, поля идут в
`properties`) получают:

- `rating: {"average": 4.6, "count": 23} | null`
- `today: {"opens": "10:00", "closes": "23:00", "open_now": true, "open_24h": false,
  "closed_today": false} | null` — `null`, если часов нет вообще.
- `address: string | null` (локаль: ru → ru, en; en → en, ru)
- `logo_url: string | null` (`MEDIA_BASE_URL/<logo_key>`)

**Рейтинг есть и в списке пинов**: дорого не вышло (один сгруппированный запрос на все id, до 1000).
`today` в списке тоже (один запрос часов на все id). Элементы `curated-routes` не менялись.

Правила `today`: `opens` — начало первого интервала дня, `closes` — конец последнего (перерыв не
показывается); `closes <= opens` — закрытие после полуночи («02:00»); круглосуточно — `open_24h: true`,
`00:00`–`23:59`; день без часов — `closed_today: true`, `opens` и `closes` равны `null` (место при этом
может быть открыто с вчерашнего интервала через полночь: `open_now: true`). `open_now` в `today` всегда
bool; верхний `open_now` карточки как раньше (`null` без часов) и теперь считается по часовому поясу
региона и по `clock.now()`.

## Отклонения

- Оценка в отзыве у Ш-44 **обязательная**, не необязательная, как в задании: так было и остаётся (отзыв
  без оценки не имеет смысла; iOS-форма Ш-44 всегда её шлёт).
- `opens`/`closes` могут быть `null` при `closed_today` (в контракте примеры только со строками).
- `data/osm/merge.py` логотипы не переносит: пока их нет, а при слиянии мест их надо будет сохранять
  (запись на будущее, когда появится загрузка логотипов).
