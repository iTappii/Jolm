# Jol — передача работы (2026-11-21)

Короткая сводка, чтобы продолжить разработку с того места, где остановились.

## Как работаем

- Источник правды — `JOL_SSOT.md`; реализация — строго по `TECH_PLAN.md` (шаги `Ш-xx` по порядку,
  DoD, статус в плане). Правила — `CLAUDE.md` и `TECH_PLAN.md §0` (без ORM, только
  параметризованный SQL через psycopg 3, миграции — новые `db/migrations/NNNN_*.sql`, старые не править).
- **После каждого шага — ревью** в `docs/reviews/Ш-xx.md`: проверить код и DoD, найти проблемы,
  исправить или записать, затем поставить статус в плане. Это требование владельца.
- Правило 8 плана: каждая новая таблица с `place_id` добавляется в `data/osm/merge.py`
  (`merge_place`) с тестом — импорт OSM сам сливает и удаляет дубли мест.
- `graphify update .` после изменений кода.

## Окружение (этот Mac)

- Docker Desktop. `make up` — PostGIS на `127.0.0.1:5433` (порт 5432 занят). `.env` из `.env.example`.
- `make valhalla-up` — Valhalla на `127.0.0.1:8002`.
- Python 3.12 в `server/.venv` (через uv); код пока держим совместимым с 3.9.
- Xcode 27.2 (симулятор iPhone 17, iOS 27.2), XcodeGen и SwiftLint установлены. `node` нет.
- iOS в симуляторе: сначала `make tiles-serve` (стиль и PMTiles на `localhost:8080`) и `make run`
  (API на `localhost:8000`), затем сборка схемы `Jol`. Тест Keychain требует подписи —
  не запускать тесты с `CODE_SIGNING_ALLOWED=NO`.
- Основные команды: `make ci` (Ruff и pytest, **473 теста зелёные**, 1 пропущен), `make migrate`, `make seed`,
  `make osm-pbf`, `make import-osm`, `make import-transit`, `make tiles`, `make run`, `make worker`,
  `make admin-create EMAIL=…` (админка: `http://localhost:8000/admin`).
