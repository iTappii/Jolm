# Jol

Mobile travel planner for Kazakhstan (iOS), AI-based. Repository is in development.

**Jol** (каз. *жол* — «дорога») — ИИ-планировщик путешествий по Казахстану для iOS.
Турист рассказывает в чате о датах, бюджете и предпочтениях, а приложение строит маршрут
на всю поездку, показывает его на карте и подбирает способы добраться до каждой точки.
Для туриста приложение бесплатное. Старт — Алматы и окрестности, далее — межгород по всему Казахстану.

## Что умеет

- Чат с ИИ, который собирает даты, бюджет, жильё и пожелания.
- Живой маршрут на карте: остановки по ходу разговора, рёбра со временем в пути.
- Маршрут по дням с учётом бюджета и жилья.
- Экран «Как добраться»: пешком, автобус, такси, самокат, своё авто.
- Погода через Open-Meteo, проверка маршрута по прогнозу.
- Избранное и вход по одноразовому коду на e-mail или по SMS.

## Стек

- **iOS:** Swift, SwiftUI, MapLibre Native, тайлы OpenStreetMap.
- **Сервер:** Python 3.12, FastAPI.
- **База:** PostgreSQL с PostGIS. Без ORM: чистый параметризованный SQL, миграции — нумерованные `.sql`-файлы.
- **Маршруты:** Valhalla (в Docker).
- **ИИ:** LLM DeepSeek (API, совместимый с OpenAI).

## Запуск локально

Требуется Docker Desktop и Python 3.12. Виртуальное окружение `server/.venv` создаётся автоматически.

1. Поднять PostgreSQL с PostGIS на `127.0.0.1:5433`. Создаст `.env` из `.env.example`, если его нет:
   ```
   make up
   ```
2. Применить миграции и (по желанию) загрузить seed-данные:
   ```
   make migrate
   make seed
   ```
3. Запустить API на `localhost:8000` (админка на `/admin`):
   ```
   make run
   ```
4. В отдельном терминале запустить воркер:
   ```
   make worker
   ```
5. Раздавать стиль карты и тайлы на `localhost:8080`:
   ```
   make tiles-serve
   ```
6. Тесты и проверка стиля кода:
   ```
   make test
   make lint
   make ci        # lint + test
   ```

Дополнительно: `make valhalla-up` поднимает Valhalla на `:8002` (первый запуск строит тайлы несколько минут),
`make import-osm` загружает места из OpenStreetMap, `make admin-create EMAIL=...` создаёт администратора.

### ИИ-ключ

ИИ-ответы идут через DeepSeek. Чтобы использовать его, в `.env` задайте:

```
LLM_PROVIDER=deepseek
DEEPSEEK_API_KEY=<ваш ключ>
```

Ключ хранится только в `.env`, в репозиторий не коммитится. Без ключа оставьте в `.env` значение
`LLM_PROVIDER=fake` (так по умолчанию в `.env.example`): ИИ-ответы тогда не настоящие, но сервер работает.
